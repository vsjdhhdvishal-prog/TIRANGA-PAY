# Tiranga Pay - Mobile Web Demo

A lightweight, mobile-first frontend application replicating the Tiranga Pay UI with multi-view support (**Home**, **Transactions**, **Profile**) and interactive forms.

## Files Included:
- `index.html` : Main HTML structure
- `style.css` : Modern CSS styles and responsive design
- `script.js` : Tab navigation, view toggle, and toast alert scripts
